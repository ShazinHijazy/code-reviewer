================================================================================
                              WHAT IT DETECTS
================================================================================

🔴 CRITICAL (Must Fix)
   ✓ eval() and exec() usage
   ✓ Hardcoded passwords/API keys
   ✓ Syntax errors

🟠 HIGH (Should Fix)
   ✓ Bare except clauses
   ✓ Dangerous error handling

🟡 MEDIUM (Code Quality)
   ✓ High cyclomatic complexity
   ✓ Functions > 50 lines
   ✓ Functions with > 5 parameters
   ✓ Global variables
   ✓ Print statements (should use logging)

🔵 LOW (Best Practices)
   ✓ Single-letter variable names
   ✓ Invalid naming conventions
   ✓ Lines > 100 characters
   ✓ Multiple statements per line
   ✓ Missing docstrings

================================================================================
                              USAGE EXAMPLES
================================================================================

COMMAND LINE:
   python cli.py file.py                    # Review single file
   python cli.py .                          # Review directory
   python cli.py file.py --format json      # JSON output
   python cli.py file.py --extension .py    # Specific extension

PYTHON API:
   from code_reviewer import CodeReviewer
   
   reviewer = CodeReviewer(code, "file.py")
   issues = reviewer.review()
   
   for issue in issues:
       print(f"Line {issue.line}: {issue.message}")

JSON OUTPUT:
   {
     "filename": "file.py",
     "total_issues": 5,
     "by_severity": {
       "critical": 1,
       "high": 1,
       "medium": 1,
       "low": 2
     },
     "issues": [...]
   }
